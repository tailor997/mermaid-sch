Schematic Diagram Demo - SVG Symbol Library

SVG Symbol Support: All components are rendered using SVG files from the symbol library.
  • Passive: resistor, capacitor, inductor, crystal
  • Semiconductor: led, diode
  • Mechanical: button
  • IC: regulator

Demo 1: SVG Resistor & Capacitor

schematic LR
    subgraph test["SVG Symbol Test"]
        title_block{
            title: "SVG Components",
            date: "2026-04-08"
        }
        
        %% Using SVG symbols from ./symbols/ directory
        [resistor R1]{label: "10k", rotation: 0}
        [capacitor C1]{label: "100nF", rotation: 90}
        [inductor L1]{label: "10uH", rotation: 0}
        
        %% Connections between components
        (VIN) (--) (0).[R1]
        [R1].(1) (--) (0).[C1]
        [C1].(1) (--) (0).[L1]
        [L1].(1) (--) (GND)
    end

Demo 2: RC Low Pass Filter (SVG)

schematic LR
    subgraph rc_filter["RC Low Pass Filter"]
        title_block{
            title: "RC Filter",
            date: "2026-04-08",
            company: "SVG Demo"
        }
        page_setting{width: 500, height: 300}
        
        [resistor R1]{label: "1k", rotation: 0}
        [capacitor C1]{label: "10uF", rotation: 90}
        
        (Ui+) (--) (0).[R1]
                        [C1].(0) (--) (Uo+)
                        [R1].(1) (--) [C1].(0)
        (Ui-) (--)      (1).[C1]
                        [C1].(1) (--) (Uo-) 
    end

Demo 3: Power Supply Decoupling (SVG)

schematic LR
    subgraph power["Power Supply"]
        title_block{
            title: "3.3V Regulator",
            date: "2026-04-08"
        }
        page_setting{width: 800, height: 400}
        
        %% Input filter
        [capacitor C_in]{label: "10uF"}
        
        %% Output filters
        [capacitor C_out1]{label: "10uF"}
        [capacitor C_out2]{label: "100nF"}
        
        %% Decoupling caps
        [capacitor C_dec1]{label: "100nF"}
        [capacitor C_dec2]{label: "100nF"}
        
        %% Connections - merged bus style
        (5V_IN) (--) (0).[C_in]
        [C_in].(1) (--) (GND)
        
        (3V3_OUT) (--) (0).[C_out1]
        (3V3_OUT) (--) (0).[C_out2]
        (3V3_OUT) (--) (0).[C_dec1]
        (3V3_OUT) (--) (0).[C_dec2]
        
        [C_out1].(1) (--) (GND_BUS)
        [C_out2].(1) (--) (GND_BUS)
        [C_dec1].(1) (--) (GND_BUS)
        [C_dec2].(1) (--) (GND_BUS)
        (GND_BUS) (--) (GND)
    end
